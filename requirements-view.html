UAV LAB WIKI · WEEK 10

第十週需求摘要 v1.0（已經使用者確認）

  • 使用對象： 初次接觸 UAV 的實驗室學弟妹。
  • 主題： Pixhawk、ArduPilot、感測器、飛行模式、Pre-Arm。
  • 來源： Holybro、ArduPilot 等官方文件，實際 ingest 至少 5 篇（本版選 8 篇）。
  • 語言： 繁體中文，專業術語首次出現附中文解釋。
  • Wiki： raw/ 來源摘錄、wiki/sources/ 來源卡、wiki/concepts/ 概念頁、wiki/index.md 與 wiki/log.md。
  • 衝突處理： 不自行選擇版本、不將差異硬湊成單一答案；標註來源、條件與待確認項。
  • 簡報： 預計 10–12 頁 HTML，面向初學者，每個技術論點有來源 ID。
  • 檢查： ingest 數量、來源覆蓋、事實忠實度、數值、HTML 連結、排版。
  • Loop 停止： 每處問題最多 3 輪；來源不足標記並停下，不編造。
  • 發布： 獨立公開 GitHub Repository + GitHub Pages。

明確邊界

  1. 不直接修改第九週已繳交的 uav-lab-wiki。
  2. 只作概念性教學，不提供任何解鎖前檢查繞過方案作為實際飛行建議；不控制真機。
  3. 第十週重點是 來源 → Wiki → 檢查 → 簡報，不擴張成即時飛控或 RAG 服務。
  4. 先取得人工確認的 outline，才開始大量產生逐頁內容與 HTML 簡報。
  5. 完成狀態必須以可檢查的實際檔案和測試輸出為準；不得虛構通過與修正紀錄。
