01 / INTERACTIVE LESSON

開始教學簡報

02 / KNOWLEDGE BASE

查看 LLM Wiki

03 / HARNESS · LOOP · GRAPH

工作流程設計

來源檢查 → Wiki → 證據卡 → 大綱人工確認 → 簡報 → 測試與局部修正。

04 / REAL EXECUTION

執行、測試與反思

保留內容忠實度、導覽版面、Graph 退回與重測紀錄；不將尚未實測的部分列為通過。

如何追溯每一頁的技術依據？

在簡報展開「本頁證據」，即可找到對應的 Wiki 來源 ID 與官方文件條目。也可以開啟 逐頁來源對照；Ingest Log 保存知識庫匯入紀錄。
