## 已整理的來源重點
1. **Overview：** Pre-Arm 檢查會在發現校正、配置或感測器資料異常時，阻止飛行器解鎖。
2. **Recognising which Pre-Arm Check has failed using the GCS：** 使用地面站可查看具體的 Pre-Arm 錯誤資訊，再依錯誤類型檢查。
3. **Warning：** 正式飛行前應排除錯誤，不以停用安全檢查作為一般排除方式。
4. **Pre-Arm Failure Messages (All vehicle types)：** 3D Accel calibration needed 對應加速度計尚未完成校正；表格分列訊息、原因與處理方式。
